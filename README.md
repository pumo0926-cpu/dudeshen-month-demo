## Demo 里可以做什么

- **点开任意一篇走完五步**：
  - **猜** 读前预判（每篇都有自己的预判题）
  - **读** 三档支架真的会变（扶＝注释块＋背景卡，半扶＝虚线词，放＝纯原文）
  - **问** 三层追问，L1/L2 可对照判分口径，**L3 不判对错但必须从原文挂一句证据才能提交**
  - **辨** 回看预判 ＋ 同龄人分布
  - **写** 轻/中/重三档，没有跳过
- 进度存 localStorage

## 文件

- `index.html` — 单文件应用，内容以 JSON 内联，无外部依赖
- `tools/tpl.html` ＋ `tools/build.py` — 由项目根目录的 `content/month01.json` 重新生成 `index.html`（`python3 tools/build.py`）
- `month01.json` — 同一份内容库的独立副本，供下游复用
