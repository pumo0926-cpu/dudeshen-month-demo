# 读得深 · 初一首月训练 Demo（H5）

**在线预览：** https://pumo0926-cpu.github.io/dudeshen-month-demo/

配套的产品方案 H5：https://pumo0926-cpu.github.io/dudeshen-reading-h5/

## 这个 demo 演示什么

一个月的初一语文阅读训练，以及**「选文全国共用、题壳按地区分」**这条成本结构。

- **月度总览**：12 篇精读 ＋ 4 个名著切片 ＋ 16 个晨读微篇 ＋ 4 次周测，合计约 4.6 小时
- **地区切换**（京津冀 / 沪 / 苏浙粤 / 川渝鄂）：切换后**选文一篇都不变**，变的只有每篇的第 7 题「地区加练」和每周的周测卷型
- **可试玩的一课**：W2 的《阿长与〈山海经〉》名著切片，完整走一遍五步法
  - **猜** 读前预判 → **读** 三档支架（扶/半扶/放，注释与背景卡真的会变）→ **问** 三层追问（L1 自动判分、L2 带反馈、L3 不判对错但必须挂文本证据）→ **辨** 回看预判＋同龄人分布＋三条不同看法 → **写** 三档输出
- **家长周报样张**：第一位永远是孩子的原话

进度存在 localStorage，点条目可手动勾完成。

## 技术说明

- 单文件 `index.html`，无外部依赖、无 CDN、无构建步骤
- 明暗模式跟随系统；进度条按 meter 规范做（空态必须读起来是空的）
- 同龄人分布用强调式条形图：你的选择用亮色，其余同色相暗一档

- 课文节选自**鲁迅《朝花夕拾·阿长与〈山海经〉》**，公有领域，原文取自维基文库并转为简体，未作改写
- 其余篇目名称为内容规格示意，非实际成品
- 周测配分为示意：按各地中考卷型的板块顺序与配分比例缩小，不代表任何官方考纲
- 初一阶段的地区差异主要在**题型外壳与配分**，不在考点范围——可以说「题型和配分跟本地一致」，不能说「押本地考点」
